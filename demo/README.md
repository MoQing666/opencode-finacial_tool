## 功能模块说明

| 模块 | 功能描述 |
|------|----------|
| **数据大屏** | 展示项目统计、投资趋势、风险分布等关键指标 |
| **项目管理** | 项目全生命周期管理，支持筛选、搜索、新建、编辑 |
| **投前管理** | 包含尽职调查、估值分析、投资决策三个子模块 |
| **投后管理** | 项目监控、绩效评估、风险预警、AI智能分析 |
| **市场信息** | 实时行情、指数走势、股票债券基金数据 |
| **Wind数据** | 对接Wind API，查询股票、债券、基金、指数数据 |
| **AI助手** | 基于本地LLaMA模型的智能投资分析助手 |
| **用户管理** | 用户权限管理、角色分配、日志审计 |

## 启动方式

### 演示版本（纯前端）
直接在浏览器中打开 `demo/index.html` 文件即可预览界面。

### 完整版本（需配置环境）
```bash
cd private-fund-system
npm install
npm run db:init
npm run dev
```
