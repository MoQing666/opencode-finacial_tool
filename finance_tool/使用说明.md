# 财务自动化工具使用说明

## 一、工具简介

本工具是一款基于Python Streamlit与Excel VBA技术构建的财务数据分析平台，专为财务人员设计。无需编程基础，通过可视化界面即可完成CSV数据导入、统计分析、图表生成和报表导出等操作，实现财务数据处理的自动化与智能化。

## 二、环境配置

**系统要求**：Python 3.8及以上版本

**安装步骤**：
1. 打开命令行工具，进入项目目录
2. 执行 `pip install -r requirements.txt` 安装依赖
3. 执行 `streamlit run app.py` 启动应用
4. 浏览器自动打开 http://localhost:8501

Windows用户可直接双击 `run.bat` 一键启动。

## 三、功能模块

### 1. 数据导入
支持上传CSV格式文件，提供UTF-8、GBK、GB2312等多种编码选项，可自定义分隔符（逗号、分号、制表符等）。系统自动验证数据完整性并显示行数、列数、缺失值等基本信息。

### 2. 统计分析
自动计算各数值列的均值、总和、标准差、最大最小值等统计指标，支持多列同时分析，以卡片形式直观展示关键数据。

### 3. 数据可视化
提供柱状图、折线图、饼图、箱线图、散点图五种图表类型，基于Plotly构建交互式图表，支持缩放、筛选等操作。

### 4. 异常检测
基于标准差方法识别数据异常值，用户可调节检测阈值，系统以红色标记异常数据点并生成分布图。

### 5. 高级分析
包含分组汇总、相关性分析、趋势分析三大功能，支持按部门、科目等维度进行交叉分析。

### 6. 报表导出
一键生成Excel格式报表，可选择导出原始数据、统计汇总、分类汇总、数据透视表等内容，支持嵌入图表。同时提供VBA模板导出功能，生成包含宏代码的专业财务报表。

### 7. 列映射配置
允许用户自定义日期列、金额列、分类列的映射关系，配置自动保存，下次使用时自动加载。

## 四、数据格式要求

工具内置两份示例数据：
- `sample_data.csv`：基础费用数据，包含日期、部门、费用类别、金额、备注字段
- `listed_company_annual_report.csv`：上市公司年报数据，包含12家公司、6个行业板块、16项财务指标

用户可参照示例格式准备自有数据。

## 五、使用流程

1. **上传数据**：点击左侧"上传CSV文件"按钮，选择文件并设置编码
2. **预览检查**：在"数据预览"标签页确认数据加载正确
3. **配置映射**：在"列映射"标签页指定日期列、金额列
4. **分析数据**：依次使用统计分析、可视化、异常检测等功能
5. **导出报表**：在"数据导出"标签页生成Excel或VBA报表

## 六、注意事项

- 单次处理数据量建议不超过10万行
- 中文乱码问题可通过切换编码格式解决
- VBA模板导出需在Excel中启用宏功能
- 所有配置自动保存于config目录

## 七、技术支持

项目结构清晰，代码模块化设计，便于扩展和定制。如需添加新功能，可参考各模块说明文档进行二次开发。
