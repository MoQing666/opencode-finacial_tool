# 财务自动化工具 - 项目总结

## 项目概述

这是一个基于 **Python Streamlit + openpyxl + Excel VBA** 的财务自动化工具，提供友好的Web界面，让不懂技术但懂财务的人员也能轻松进行财务数据分析。

## 技术栈

| 技术 | 用途 | 版本 |
|------|------|------|
| Python | 后端逻辑 | 3.8+ |
| Streamlit | Web界面 | 1.60.0 |
| Pandas | 数据处理 | 3.0.5 |
| openpyxl | Excel操作 | 3.1.5 |
| Plotly | 数据可视化 | 6.9.0 |
| Excel VBA | 报表自动化 | - |

## 项目结构

```
finance_tool/
├── app.py                 # Streamlit主应用（入口）
├── data_processor.py      # 数据处理模块
├── excel_handler.py       # Excel处理模块
├── config_manager.py      # 配置管理模块
├── test_startup.py        # 测试脚本
├── requirements.txt       # Python依赖
├── run.bat               # Windows启动脚本
├── README.md             # 项目说明文档
│
├── data/                 # 数据文件夹
│   └── sample_data.csv   # 示例数据（50条）
│
├── output/               # 输出文件夹（存放导出的报表）
│
└── vba/                  # VBA模板文件夹
    ├── financial_macros.vba  # VBA宏代码
    └── README_VBA.md     # VBA使用说明
```

## 功能模块

### 1. 数据导入模块
- 支持CSV文件上传
- 多种编码格式（UTF-8、GBK、GB2312等）
- 自定义分隔符
- 数据验证和错误提示

### 2. 统计分析模块
- 基本统计指标（均值、总和、标准差、最大/最小值等）
- 多列同时分析
- 统计卡片展示

### 3. 数据可视化模块
- 柱状图
- 折线图
- 饼图
- 箱线图
- 散点图
- 交互式图表（支持缩放、筛选）

### 4. 异常检测模块
- 基于标准差的异常值检测
- 可调节阈值
- 异常值可视化

### 5. 高级分析模块
- 分组汇总
- 相关性分析
- 趋势分析

### 6. 报表导出模块
- Excel格式导出
- 多种导出选项（原始数据、统计汇总、分类汇总、数据透视表）
- VBA模板导出
- 图表嵌入

### 7. 配置管理模块
- 列映射配置
- 导出设置
- 显示设置
- 配置持久化

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行应用
```bash
streamlit run app.py
```
或者双击 `run.bat`

### 3. 访问应用
浏览器会自动打开 http://localhost:8501

## 常见问题

### Q: 中文乱码怎么办？
A: 尝试不同的编码格式（GBK、GB2312、UTF-8）

### Q: 如何处理大文件？
A: 建议单次处理不超过10万行，或使用分批处理

### Q: 如何自定义报表样式？
A: 修改 `excel_handler.py` 中的样式定义

### Q: VBA模板如何使用？
A: 参考 `vba/README_VBA.md` 文档
