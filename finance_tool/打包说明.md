# 打包为EXE指南

## 方案对比

| 方案 | 文件 | 启动方式 | 窗口样式 | 体积 |
|------|------|----------|----------|------|
| A | `launcher.py` | 自动打开浏览器 | 浏览器窗口 | ~15MB |
| B | `desktop.py` | 原生桌面窗口 | 独立窗口 | ~50MB |

## 快速打包（推荐方案A）

```bash
cd finance_tool
build.bat
```

打包完成后，`dist/财务自动化工具.exe` 即可直接运行。

## 手动打包

### 方案A：浏览器模式

```bash
# 安装依赖
pip install pyinstaller streamlit pandas openpyxl plotly

# 打包
pyinstaller --onefile --windowed --name "财务自动化工具" ^
    --add-data "app.py;." ^
    --add-data "data_processor.py;." ^
    --add-data "excel_handler.py;." ^
    --add-data "config_manager.py;." ^
    --add-data "data;data" ^
    --add-data "vba;vba" ^
    launcher.py
```

### 方案B：原生窗口模式

```bash
# 额外安装pywebview
pip install pywebview

# 打包
pyinstaller --onefile --windowed --name "财务自动化工具" ^
    --add-data "app.py;." ^
    --add-data "data_processor.py;." ^
    --add-data "excel_handler.py;." ^
    --add-data "config_manager.py;." ^
    --add-data "data;data" ^
    --add-data "vba;vba" ^
    desktop.py
```

## 使用spec文件打包

```bash
pyinstaller build.spec
```

## 注意事项

### 1. Python环境要求
打包后的exe仍需要目标机器安装Python环境（Streamlit依赖）。

如需完全独立运行，可使用：
- **PyInstaller + --collect-all streamlit** 收集所有依赖
- **Nuitka** 编译为C++（更复杂但更独立）

### 2. 文件路径问题
打包后的工作目录可能变化，代码已处理：
```python
if getattr(sys, 'frozen', False):
    app_dir = os.path.dirname(sys.executable)  # exe所在目录
else:
    app_dir = os.path.dirname(__file__)  # 脚本所在目录
```

### 3. 防火墙提示
首次运行可能触发防火墙提示，选择允许即可。

### 4. 杀毒软件误报
PyInstaller打包的exe可能被误报，添加信任即可。

## 分发给他人使用

### 最简方案（需要Python环境）
1. 将整个 `finance_tool` 文件夹打包为zip
2. 对方解压后运行 `build.bat` 或直接运行 `desktop.py`

### 完整方案（推荐）
1. 在你本机执行打包
2. 将 `dist/财务自动化工具.exe` 打包发送
3. 对方需安装Python并添加到PATH

### 最佳方案（完全独立）
使用Docker或虚拟机打包完整环境，但体积会很大（~500MB）。

## 常见问题

**Q: 打包后启动失败？**
A: 检查app.py是否在exe同级目录，或重新打包确保--add-data正确

**Q: 如何添加图标？**
A: 在spec文件中设置 `icon='logo.ico'`，或打包时添加 `--icon logo.ico`

**Q: 如何减小体积？**
A: 使用 `--exclude-module` 排除不需要的模块，或使用UPX压缩
