# Excel VBA 模板使用说明

## 概述

本目录包含财务自动化工具的VBA宏代码，可以在Excel中实现自动化的财务报表生成和数据处理功能。

## 文件说明

- `financial_macros.vba` - 主要的VBA宏代码文件

## 安装步骤

### 方法一：导入VBA代码

1. 打开Excel
2. 按 `Alt + F11` 打开VBA编辑器
3. 在左侧"工程资源管理器"中右键点击你的工作簿
4. 选择"导入文件"
5. 选择 `financial_macros.vba` 文件
6. 保存为 `.xlsm` 格式（启用宏的工作簿）

### 方法二：直接复制代码

1. 打开Excel
2. 按 `Alt + F11` 打开VBA编辑器
3. 在左侧"工程资源管理器"中双击"ThisWorkbook"
4. 将 `financial_macros.vba` 中的代码复制粘贴到代码窗口
5. 保存为 `.xlsm` 格式

## 功能说明

### 1. 生成财务报表 (GenerateFinancialReport)

**功能**：自动生成完整的财务综合报表

**包含内容**：
- 报表标题和基本信息
- 汇总统计（各科目金额、占比、均值等）
- 数据明细
- 柱状图和饼图

**使用方法**：
1. 确保工作簿中有"财务数据"工作表
2. 运行宏 `GenerateFinancialReport`
3. 自动生成"财务报表"工作表

### 2. 部门汇总 (SummarizeByDepartment)

**功能**：按部门汇总财务数据

**包含内容**：
- 各部门金额汇总
- 占比分析
- 饼图展示

**使用方法**：
1. 确保数据中有"部门"和"金额"列
2. 运行宏 `SummarizeByDepartment`
3. 自动生成"部门汇总"工作表

### 3. 导出为PDF (ExportToPDF)

**功能**：将财务报表导出为PDF格式

**使用方法**：
1. 运行宏 `ExportToPDF`
2. 选择保存位置
3. 自动生成PDF文件

### 4. 导出为Excel (ExportToExcel)

**功能**：将报表导出为新的Excel文件

**使用方法**：
1. 运行宏 `ExportToExcel`
2. 选择保存位置
3. 生成独立的Excel文件

### 5. 清空报表 (ClearReport)

**功能**：清除所有生成的报表工作表

**使用方法**：
1. 运行宏 `ClearReport`
2. 确认删除
3. 保留原始数据工作表

### 6. 刷新数据 (RefreshData)

**功能**：重新加载和刷新数据

**使用方法**：
1. 运行宏 `RefreshData`
2. 自动刷新数据

### 7. 显示帮助 (ShowHelp)

**功能**：显示使用帮助信息

## 数据格式要求

### 必需列

- **部门**：部门名称
- **金额**：财务金额（数字格式）

### 可选列

- **日期**：交易日期
- **费用类别**：费用类型
- **备注**：补充说明

| 2024-01-08 | 技术部 | 办公费 | 800 | 购买设备 |

## 自定义配置

### 修改样式

在VBA代码中可以修改以下样式：

```vba
' 修改标题颜色
ws.Range("A1").Font.Color = RGB(31, 119, 180)

' 修改表头背景色
.Range("A6:F6").Interior.Color = RGB(31, 119, 180)

' 修改数字格式
.Cells(row, 2).NumberFormat = "#,##0.00"
```

### 添加新功能

可以在VBA编辑器中添加新的Sub过程来扩展功能：

```vba
Sub MyCustomFunction()
    ' 自定义代码
End Sub
```

## 常见问题

### Q: 运行宏时提示"宏已被禁用"
A: 
1. 文件 → 选项 → 信任中心 → 信任中心设置
2. 宏设置 → 选择"启用所有宏"
3. 或者将文件添加到受信任位置

### Q: 数据列名不匹配
A: 使用 `FindColumn` 函数自动查找列名，或修改代码中的列名

### Q: 如何添加新的图表类型
A: 使用 `CreateCharts` 函数中的示例代码，修改 `ChartType` 属性

### Q: 如何修改报表格式
A: 修改 `FormatReport` 函数中的样式设置

## 注意事项

1. **保存格式**：必须保存为 `.xlsm` 格式才能保存宏
2. **宏安全性**：确保宏安全设置允许运行
3. **数据备份**：运行宏前建议备份原始数据
4. **版本兼容**：建议使用Excel 2016及以上版本
